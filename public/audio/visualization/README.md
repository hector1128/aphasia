# Visualization recordings

Drop MP3 files in this folder with these exact names. No code edits are needed:

- `beach.mp3` — Ocean Shore / Beach Scene
- `forest.mp3` — Lush Forest / Woodland Stroll
- `lake.mp3` — Boundless Lake / Moonlit Water
- `light.mp3` — Healing / White Light Bath
- `balloon.mp3` — Floating Balloon Release
- `candle.mp3` — Candle Flame Focus

The player never auto-plays. It supports play/pause, seeking, and replay with native controls.
A completed recording records one mindfulness session. The manual completion button uses the same session, so it is not counted twice.
Until a recording exists, the theme description and manual completion remain available.
